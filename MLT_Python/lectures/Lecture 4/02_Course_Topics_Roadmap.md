# Topic 2: Course Topics Roadmap (Full Syllabus Breakdown)

Source: Lecture 4, slide 12 ("Topics").

## 1) Technical Explanation

This slide lists the complete set of topics the course (ES514) will cover, organized into 11 categories — effectively a detailed expansion of the brief syllabus roadmap first shown in Lecture 1 ([[06_Course_Syllabus_Roadmap_and_Resources]] from Lecture 1):

1. **Foundations**: Probability, Optimization — the mathematical prerequisites underlying almost every ML algorithm.
2. **Classification**: KNN (K-Nearest Neighbors), Logistic Regression, **Perceptron** (the exact topic covered in the rest of this lecture).
3. **Regression**: Linear Regression.
4. **Important Concepts**: Kernels, Regularization and Overfitting, Experimental Design — cross-cutting ideas that apply across many algorithms.
5. **Unsupervised Learning**: K-means (clustering), PCA (Principal Component Analysis, for dimensionality reduction).
6. **Neural Networks**: Feedforward Neural Nets, Basic architectures, Backpropagation.
7. **Deep Learning**: CNNs (Convolutional Neural Networks), RNNs (Recurrent Neural Networks), Transformers.
8. **Reinforcement Learning** (formal, algorithmic treatment — building on Topic 0's intuitive introduction): Value Iteration / Policy Iteration, Q-Learning, Deep Q-Learning, PAC Learning.
9. **Learning Theory**: PAC Learning (Probably Approximately Correct learning — a formal mathematical framework for analyzing how much data is needed to learn reliably).
10. **Societal Impacts of ML**: a dedicated topic on the ethical/social consequences of deploying ML systems.
11. **Other Learning Paradigms**: Matrix Factorization, Ensemble Methods.

This roadmap is the most detailed version of the course syllabus given so far, and directly maps onto the ML Big Picture framework from Topic 1 — e.g., "Learning Paradigms" and "Facets of Building ML Systems" from that map are exactly what these 11 categories operationalize into a semester's worth of specific lectures.

## 2) Simple English Explanation

This slide is essentially the **table of contents for the entire course** — a complete list of every major topic you'll study, grouped into logical sections:

- **Foundations** — the math basics you need first (Probability, Optimization).
- **Classification** — methods for sorting data into categories: KNN, Logistic Regression, and the **Perceptron** (which this very lecture is about to explain in detail).
- **Regression** — methods for predicting numbers: Linear Regression.
- **Important Concepts** — ideas that show up again and again across different methods: Kernels (a trick for handling complex patterns), Regularization/Overfitting (preventing a model from "memorizing" instead of learning), and how to properly design experiments.
- **Unsupervised Learning** — K-means (for grouping data) and PCA (for simplifying/compressing data).
- **Neural Networks** — the building blocks of modern AI: basic network structures and how they learn (Backpropagation).
- **Deep Learning** — more advanced/powerful neural networks: CNNs (great for images), RNNs (great for sequences like text), and Transformers (the technology behind tools like ChatGPT).
- **Reinforcement Learning** (in full technical depth this time) — specific algorithms like Q-Learning and Deep Q-Learning.
- **Learning Theory** — the mathematical theory behind why/how learning works, including something called PAC Learning.
- **Societal Impacts of ML** — a topic specifically about the real-world, ethical effects of using ML in society.
- **Other Learning Paradigms** — a couple of extra techniques: Matrix Factorization and Ensemble Methods (combining multiple models together).

This is your complete "menu" for the semester — every topic here will come up again in later lectures.
