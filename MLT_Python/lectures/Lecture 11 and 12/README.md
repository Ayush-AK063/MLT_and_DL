## Notes on this lecture

- **Opens with expanded Feature Selection content, not a pure recap.** Lecture 10's slides only *named* Filter/Wrapper/Embedded with zero elaboration (that file, [[04_Feature_Selection_Methods_Filter_Wrapper_Embedded]], was built entirely from web research). This lecture's own slides (1–9) finally supply the instructor's own definitions, a process diagram, a Python-library table, and — most notably — a real applied worked example. Since this is genuinely new content (not a verbatim repeat), full topic files were written rather than a short recap-note, but they cross-reference Lecture 10's file rather than re-deriving the same pros/cons analogy.
- **Real research paper as a worked example:** slides 7–9 reproduce a table and figure directly from Patel, Y.S., Jaiswal, R. & Misra, R., "Deep learning-based multivariate resource utilization prediction for hotspots and coldspots mitigation in green cloud data centers," J Supercomput 78, 5806–5855 (2022) — **the lead author is this course's own instructor, Dr. Yashwant Singh Patel.** Four of the six statistical methods used in that example (Kendall's Tau, ANOVA, Granger causality, Mutual Information) were named but not explained on the slide, and are fully explained via web research in [[02_Feature_Selection_Worked_Example_Resource_Metrics]].
- **PCA is the main event of this lecture** (slides 12–34) and is covered far more mechanically than Lecture 10's research-built overview ([[07_Feature_Extraction_PCA_SVD_LDA]] from Lecture 10) — the source slides now walk through the actual formulas (covariance matrix, det(A−λI)=0, [A−λI]X=0) and a fully worked numeric example.
- **Verified the full PCA worked example independently** (slides 23–32): recomputed the covariance matrix (Cov(X,X)=0.6165, Cov(Y,Y)=0.7165, Cov(X,Y)=0.6154 — all match), recomputed the eigenvalues via the quadratic trace/determinant formula (λ₁≈1.284, λ₂≈0.049 — match within rounding), verified both eigenvectors are unit-length and mutually orthogonal (dot product = 0, confirming PCA's perpendicularity guarantee), and confirmed the 96%/4% variance split. See [[06_PCA_Worked_Example_Covariance_Eigen]] for the full verification.
- **Identified the worked example's source:** the 10-point (X,Y) dataset used in slides 23–32 is the classic dataset from Lindsay I. Smith's widely-cited 2002 tutorial *"A Tutorial on Principal Component Analysis"* — confirmed via web research, noted in [[06_PCA_Worked_Example_Covariance_Eigen]].
- **No anomalies flagged** — every slide in this deck is on-topic for the course (Feature Selection recap/extension and Principal Component Analysis), with the sole non-technical slide being a Google Photos application screenshot (slide 12) used purely as a motivating example before the PCA math begins, covered briefly in [[03_Feature_Extraction_Recap]].
